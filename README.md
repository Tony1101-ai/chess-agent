# chess-agent
An AI-powered chess assistant built with GPT-4o-mini and LangChain Agent. Supports uploading chessboard images for automatic FEN recognition, move analysis, and strategic suggestions. Interactive UI powered by Gradio. Live demo: https://yantaotang-chess-agent.hf.space. You can also find pth files in https://huggingface.co/spaces/yantaotang/chess_agent/tree/main
